核心特性：
-----------

1. 资源自动管理
   - try-with-resources 支持
   - 自动 pin/unpin 所有页面
   - 防止资源泄漏

2. 原子性保证
   - 多个页面的修改原子提交
   - 失败自动回滚
   - ACID 语义

3. 脏页追踪
   - 显式 markDirty() 标记
   - commit 时传播到 BufferPool
   - 加入 FlushList

4. 性能优化
   - 页面缓存（避免重复获取）
   - LIFO 释放顺序
   - 支持虚拟线程

使用模式：
-----------

// 推荐模式
try (MiniTransaction mtr = new MiniTransaction(bufferPool)) {
    Page page = mtr.getPage(pageId);
    page.putInt(offset, value);
    mtr.markDirty(page);
    mtr.commit();
}

关键规则：
-----------

1. ✅ 始终使用 try-with-resources
2. ✅ 修改后必须 markDirty
3. ✅ 显式 commit 或 rollback
4. ✅ 一个 MTR 一个线程
5. ❌ 不要跨 MTR 使用 Page 对象

与 MySQL InnoDB 的对应：
--------------------------

InnoDB          MiniDB
