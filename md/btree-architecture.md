# B+Tree 架构设计

## 1. 设计原则

### 1.1 核心不变量

1. **有序性**: 所有键在叶子节点中按顺序排列
2. **平衡性**: 从根到任意叶子的路径长度相同
3. **填充因子**: 每个节点至少半满（根节点除外）
4. **叶子链表**: 叶子节点通过双向链表连接
5. **WAL 优先**: 所有修改先写日志再写数据页

### 1.2 设计目标

- **高性能**: O(log N) 的查找、插入、删除
- **高并发**: 支持多线程并发访问
- **持久性**: 崩溃后可完整恢复
- **可扩展**: 支持多种索引类型

## 4. 树结构

### 4.1 多层结构

```
                    ┌─────────────┐
                    │    Root     │  Level 2
                    │  [30, 60]   │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           ↓               ↓               ↓
    ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
    │  Internal   │ │  Internal   │ │  Internal   │  Level 1
    │ [10, 20]    │ │ [40, 50]    │ │ [70, 80]    │
    └──────┬──────┘ └──────┬──────┘ └──────┬──────┘
     ┌─────┼─────┐   ┌─────┼─────┐   ┌─────┼─────┐
     ↓     ↓     ↓   ↓     ↓     ↓   ↓     ↓     ↓
   ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
   │L1 │↔│L2 │↔│L3 │↔│L4 │↔│L5 │↔│L6 │↔│L7 │↔│L8 │↔│L9 │  Level 0
   └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘
                     Leaf Level (双向链表)
```

### 4.2 节点类型

| 类型 | Level | 特点 |
|------|-------|------|
| 根节点 | 最高 | 可以少于半满 |
| 内部节点 | 1 ~ height-1 | 存储子页面指针 |
| 叶子节点 | 0 | 存储实际数据，双向链表连接 |

## 5. 元数据管理

### 5.1 BTreeMetadata

```java
public class BTreeMetadata {
    private final long indexId;      // 索引 ID
    private final int spaceId;       // 空间 ID
    private int rootPageNo;          // 根页面号
    private int treeHeight;          // 树高度
    private long recordCount;        // 记录数
    private int leafPageCount;       // 叶子页面数
    private int internalPageCount;   // 内部页面数
}
```

### 5.2 IndexDescriptor

```java
public class IndexDescriptor {
    private final long indexId;           // 索引 ID
    private final String indexName;       // 索引名称
    private final long tableId;           // 表 ID
    private final IndexType indexType;    // 索引类型
    private final List<ColumnDescriptor> columns;  // 列定义
    private int rootPageNo;               // 根页面号
    private int treeHeight;               // 树高度
    private long recordCount;             // 记录数
}
```

## 8. 配置参数

| 参数 | 默认值 | 描述 |
|------|--------|------|
| PAGE_SIZE | 16KB | 页面大小 |
| BUFFER_POOL_SIZE | 1000 | 缓冲池页面数 |
| WAL_BUFFER_SIZE | 64KB | WAL 缓冲区大小 |
| MAX_LOG_FILE_SIZE | 16MB | 单个日志文件最大大小 |
| COMPRESSION_THRESHOLD | 0.8 | 压缩阈值 |
| BULK_LOAD_FILL_FACTOR | 0.9 | 批量加载填充因子 |
